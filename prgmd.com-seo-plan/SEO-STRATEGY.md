## 3. Current State — What's Working & What's Not

### Working
1. **Colorado state page** (`/medical-billing-in-colorado/`) — 2,049 traffic/mo, ranks #4 for "medical billing services" (vol 3,200, KD 24). This page alone is responsible for the bulk of organic discovery.
2. **Glossary content** — POS codes, credentialing, COB, EOR, ABN, retro-authorization, AR follow-up, denial codes, EDI, entity codes, professional-vs-institutional claims. ~20 pages each capturing 20–150 visits/month. Cumulatively ~1,200 traffic.
3. **Brand** — #1 for "physicians revenue group" and "prgmd". Branded demand is captured.
4. **Backlink profile** — 631 live referring domains, 337 of which point at the homepage. DR 41 is workable foundation.

### Not Working
1. **Specialty service pages absent from top 25 by traffic.** URLs like `/cardiovascular-medical-billing-company/`, `/chiropractic-medical-billing-company/` exist but rank poorly — high-CPC, high-intent terms ($700 CPC for "cardiology medical billing") are leaving money on the table.
2. **Other state pages underperform.** Maryland (#2, 96/mo), Missouri, Delaware, Kansas, Ohio all rank well but earn fractional traffic vs Colorado. Not 50 states; gaps in CA, TX, FL, NY (largest healthcare markets).
3. **"Revenue cycle management"** (vol 13,000, KD 20, $26K traffic potential) — they don't rank. Core money keyword absent.
4. **"Medical billing outsourcing"** (vol 1,500, KD 0) — KD zero, completely unowned, no dedicated page.
5. **Glossary pages plateau at #4–15.** Many on-page improvements possible: schema, internal linking, content depth.
6. **Three pages drive everything.** Colorado / POS-21 / professional-vs-institutional account for ~65% of traffic. Brittle.
7. **Homepage traffic is tiny (118/mo).** It has the link equity (337 ref domains) but isn't optimized to rank for any volume keyword.

## 4. Strategic Priorities (in order)

### P1 — Replicate the Colorado playbook to top healthcare-spend states (months 1–4)
The Colorado page works because it intercepts geo-modified intent for "medical billing services" with a focused, locally-flavored landing page. Build the same page for the next 9 states by Medicare spend / physician count: **CA, TX, FL, NY, PA, IL, OH, GA, NC, MI**. Each page ~1,200 words, schema'd as ProfessionalService + areaServed, internal-linked from a `/services/medical-billing-by-state/` hub.

Conservative outcome: 9 × 800 traffic = +7,200/mo organic.

### P2 — Build specialty vertical hubs (months 1–6)
PRG already mentions specialties. Convert each into a tier-1 service page:
- `/cardiology-medical-billing/` (vol 250, KD 3, CPC $700)
- `/chiropractic-medical-billing/` (vol 100, KD 0, CPC $700)
- `/mental-health-billing/` (vol 1,000, KD 17)
- `/dental-billing/` (vol 600, KD 43 — competitive but lucrative)
- `/podiatry-billing/` (vol 600, KD 0, CPC $1,300)
- Plus: family practice, internal medicine, pediatrics, OB-GYN, dermatology, orthopedics, gastroenterology

Each: case study, specialty-specific pain points (e.g., cardiology = 93000-series CPT codes), pricing model, schema with `Service` type.

### P3 — Win "revenue cycle management" cluster (months 2–8)
13K-volume head term they don't rank for. Build a hub-and-spoke:
- Hub: `/revenue-cycle-management/` — pillar page, 2,500+ words, definitive
- Spokes: RCM steps, RCM KPIs, RCM software vs services, RCM for small practices, RCM denial management, RCM outsourcing, RCM audit, etc. Most of these are already in glossary form — re-link and re-position under the pillar.

KD 20, traffic potential 26,000. Realistic capture: 1,500–3,000/mo at #4–8.

### P4 — Author E-E-A-T overhaul (months 1–3, low-effort, high-leverage)
Glossary articles are currently anonymous. Add:
- Author bylines with `Person` + `ProfilePage` schema for medical-coding-credentialed staff (CPC, CPB, CPMA)
- Reviewer line ("Medically reviewed by [name, credentials]")
- Expertise statements on service pages
- About page with team credentials, certifications (HBMA, HFMA membership), HIPAA compliance posture, SOC 2 status

This is the single highest-leverage move for AI-search citation (Perplexity, ChatGPT, Google AI Overviews) and YMYL (Your-Money-Your-Life) trust signals — medical billing falls under YMYL.

### P5 — GEO / AI-search optimization (months 3–9)
Run `/seo geo` separately. Targets:
- llms.txt
- Passage-level citability (numbered lists, definitions, stat-rich paragraphs)
- Brand-mention building on healthcare publications (Becker's, RevCycleIntelligence, MGMA)
- FAQ schema on glossary pages (currently restricted but verify YMYL eligibility)

### P6 — Defensive: protect Colorado page
It's a single point of failure. Add internal links INTO it from new state pages, glossary articles, and homepage. Build 5–10 high-quality backlinks to it specifically. Update it quarterly. Add aggregate review schema if any are visible on the page.

## 6. Risks & Dependencies

| Risk | Mitigation |
|---|---|
| Colorado page deindexed / ranking drop | Quarterly content refresh, internal links from all new state pages, monitor with `/seo drift` baselines |
| Programmatic state pages flagged as thin | Each page must be unique: local statistics (Medicare spend, physician count, top hospital systems), state-specific compliance notes (e.g., NY no-fault, FL PIP), local case study or testimonial |
| Specialty pages cannibalize each other | Strict topical separation; one page per specialty + state matrix only when search volume justifies (e.g., Cardiology Texas — only if vol > 50) |
| YMYL trust deficit | E-E-A-T overhaul (P4) is non-negotiable; medical billing is YMYL by Google's standards |
| Limited content production capacity | Phase 1 = 9 state pages (~1,200 words each) = ~30 hours of skilled writing; budget for it explicitly |
| AAPC / CMS / AMA dominate informational queries | Don't try to outrank them on definitions; instead capture commercial intent (services, comparisons, pricing) where they don't compete |

## 7. What This Plan Does NOT Cover

- **Maps / Local SEO** — low value for B2B national service. See `/seo-maps` if pursuing local visibility around Downers Grove HQ.
- **Paid search** — already running 8 keywords; coordinate with paid team to avoid bidding on terms you'll soon rank for organically (e.g., "medical billing services" — currently #4 organic, paying for clicks).
- **Conversion rate optimization** — out of scope; assume current site converts traffic acceptably.
- **International expansion** — no signals of non-US targeting; ignore for now.
